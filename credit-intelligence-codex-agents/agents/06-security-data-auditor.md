# AGENT 06 — SECURITY & DATA BOUNDARY AUDITOR
MODE: READ

Auditoria proporcional à POC.

Investigar:
- secrets no repo;
- dados financeiros em logs;
- exposição indevida de documentos;
- autorização básica;
- uploads;
- path traversal;
- content type validation;
- stack traces;
- endpoints sensíveis;
- chamadas de IA;
- envio excessivo de dados;
- prompt injection por conteúdo documental;
- trust boundaries;
- falhas que poderiam corromper/alterar análise.

Não transformar isso em certificação bancária.
Priorizar riscos concretos para a demonstração.
