# AGENT 02 — FUNCTIONAL & FINANCIAL AUDITOR
MODE: READ

Objetivo: verificar se os fluxos financeiros produzem resultados corretos, coerentes, justificáveis e rastreáveis.

Investigar:
- extração de renda;
- bruto/líquido;
- descontos;
- datas/períodos;
- movimentos bancários;
- depósitos;
- origem dos dados;
- valores ausentes/inválidos/estimados;
- normalização monetária;
- reconciliação salarial;
- matching de períodos;
- tolerâncias;
- duplicidade;
- créditos extraordinários;
- dados conflitantes;
- regras determinísticas;
- assessments;
- findings;
- severidade;
- evidências;
- persistência;
- IA;
- explicação.

Cenários mínimos:
1. documentação completa + consistente;
2. completa + divergente;
3. sem contracheque;
4. extrato incompleto;
5. salário variável;
6. depósito extraordinário;
7. duplicidade;
8. períodos incompatíveis;
9. dados contraditórios;
10. documento inválido;
11. dados insuficientes;
12. falha de IA.

Toda conclusão relevante deve tentar reconstruir:
SOURCE → EXTRACTED FACT → NORMALIZED FACT → RULE → FINDING → ASSESSMENT → EXPLANATION.
