## Protocolo de evidência
Guardar localmente apenas referências de captura autorizadas, não incorporar assets no kit: `ID`, URL final, data/hora, página/viewport, método (browser/PDF), observação, `OBSERVADO|ESTIMADO|PROPOSTO`, confiança, licença, link para evidência. Falhas de acesso devem constar do registro.

## Leitura crítica
Algumas marcas evoluem ao longo dos anos. A descrição de 2016 evidencia uma fase documentada, não confirma cada detalhe da apresentação atual. Nenhum HEX, fonte ou grid numérico deste kit é declarado oficial.
