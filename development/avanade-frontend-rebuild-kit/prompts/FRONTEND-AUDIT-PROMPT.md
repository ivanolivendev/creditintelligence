# Prompt da Fase 1 — auditoria sem mutação

Inspecione em modo leitura o projeto real conforme `workflows/FRONTEND-AUDIT.md`. Mapeie framework/build, versões, dependências, boundary frontend/backend, estrutura, roteamento, code splitting, estado global, validações, formulários, tabelas, dashboards, notificações, internacionalização, tema, autenticação e autorização, APIs, DTOs, erros, loading e empty states. Não exponha tokens ou dados reais.

Para cada rota, cubra: URL, página, papel autorizado, entrada, ações, integrações, estados, testes e risco. Gere inventário conforme template. Verifique indicadores de dívida: duplicação, CSS global frágil, dependências abandonadas, problemas de contraste, foco e layout, sem refatorar.

**Entregue:** árvore relevante, baseline, matriz de contratos preservados, relatório de auditoria preenchido, perguntas bloqueantes, mapa de risco e cobertura de testes. Distinguir fatos verificados de inferências.
