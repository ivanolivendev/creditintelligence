# Prompt da Fase 3 — projeto de design system

Leia `specs/DESIGN-SYSTEM-SPECIFICATION.md`, `specs/ACCESSIBILITY-REQUIREMENTS.md` e o inventário real de telas. Proponha tokens e componentes adequados à stack detectada. Todos os tokens devem carregar `origem`, `status de evidência`, `confiança`, `responsável` e `justificativa`; valores numéricos são propostas de implementação, não valores oficiais.

Documente sistema de cores semânticas (texto, fundo, borda, ação, feedback), gradientes expressivos de uso contido, contrastes e estado sem cor; tipografia licenciada, espaços, densidades, grid, radius, sombras, foco, motion/reduced-motion e breakpoints derivados de conteúdo. Faça inventário de componentes e matriz de estados/variantes/keyboard/accessibility.

**Entregue:** tokens em template, componentes prioritários, padrões de página, mapa de migração e justificativas para áreas neutras versus áreas vibrantes. Não implemente nesta fase.
