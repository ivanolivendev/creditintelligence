# Analyst workspace

## Why

The API journey is verified but an analyst still needs a usable interface to create a synthetic proposal, add a document, inspect evidence, and record a decision.

## What changes

- Add a React, TypeScript and Vite single page workspace served through Compose.
- Keep demo credentials in memory and proxy API calls through the same origin.
- Show proposal, document versions, analysis state, findings, evidence, AI mock status, and human decision explicitly.
- Verify build, lint, and a browser end-to-end journey with synthetic data.
